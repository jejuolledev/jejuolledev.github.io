이중 슬릿, 슈뢰딩거의 고양이, 양자 얽힘. 말로만 듣던 실험 21개를 직접 돌려보며 배웁니다.

  • 인터랙티브 실험 21개 (양자 16 + 태양계 5) — 전부 무료
  • 4단계 학습 루프: 개념 카드 → 실험 → 퀴즈 → 다음 추천
  • 12칸 개념 사다리 · 용어사전 115개
  • 한국어 · English · 日本語
  • 로그인 없음 · 인앱 결제 없음 · 오프라인 학습

결제가 있나요?

없습니다. 판매하는 상품이 하나도 없어 실수로 결제될 일이 없습니다. 모든 학습 콘텐츠가 무료입니다.

광고는 어떻게 나오나요?

화면 하단 배너만 사용합니다. 화면을 가로막는 전면 광고와 보상형 광고는 쓰지 않고, 실험을 조작하는 화면에서는 광고를 표시하지 않습니다. 비개인화 광고만 요청합니다.

학습 기록은 어디에 저장되나요?

사용 중인 기기 안에만 저장되며 외부로 전송되지 않습니다. 앱을 삭제하면 함께 삭제됩니다.

인터넷이 없어도 되나요?

네. 학습 기능은 오프라인에서 전부 그대로 동작합니다.
